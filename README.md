# Civic Echo

A web platform that empowers citizens to report people who break public cleanliness rules, such as dumping garbage or causing waterlogging in places where it is prohibited.

🌐 **Live site:** [civicecho-lovat.vercel.app](https://civicecho-lovat.vercel.app)

## Why Civic Echo?
Littering and blocked drainage harm public health and cause waterlogging in our cities. Civic Echo gives people a simple way to speak up and report violations so that the issue can be noticed and addressed.

## Features
- Report people who dump waste or cause waterlogging in prohibited areas
- Simple, easy-to-use web interface
